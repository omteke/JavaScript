data binding in angular:-
one way data binding types-------->
interpolation ---> {{value}} -----> shows data from ts in HTML
property ----> [property] = "value" ----> binding data from ts to HTML element property
event ----> (event) = "handler()" ----> binding event from HTML element to ts method
two way ----> [(ngModel)] = "value" ----> binding data from ts to HTML and HTML to ts (requires FormsModule)

activity1:- how we can use for loop,switch cases and ef-else block in angular.

In Angular, we use special directives in HTML templates for loops, conditions, and switches (not raw JavaScript). Here’s a simple breakdown with examples. I’ll assume you’re working in `app.component.ts` and `app.component.html` in your `my-first-app` project.

### 1. **For Loop: `*ngFor`**
   - Loops over a list (array) and repeats HTML for each item.
   - Example: Show a list of fruits.

   In `app.component.ts:
  
   export class AppComponent {
     fruits = ['Apple', 'Banana', 'Orange'];
   }
   

   In `app.component.html
   html
   <ul>
     <li *ngFor="let fruit of fruits">{{ fruit }}</li>
   </ul>

   - Output: A list like "Apple", "Banana", "Orange".

### 2.If-Else: *ngIf
   - Shows or hides content based on true/false.
   - Use else for the "otherwise" part.

   **In app.component.ts

   export class AppComponent {
     isVisible = true;
   }
  

   In app.component.html
   html
   <p *ngIf="isVisible; else hidden">Hello!</p>
   <ng-template #hidden>
     <p>Goodbye!</p>
   </ng-template>
   
   - Output: "Hello!" if `isVisible` is true; otherwise "Goodbye!".

### 3. Switch Case: *ngSwitch
   - Checks a value and shows matching content.

   **In app.component.ts
   typescript
   export class AppComponent {
     day = 'Monday';
   }
  

   In app.component.html
   html
   <div [ngSwitch]="day">
     <p *ngSwitchCase="'Monday'">Start of week</p>
     <p *ngSwitchCase="'Friday'">Almost weekend</p>
     <p *ngSwitchDefault>Regular day</p>
   </div>
   
   - Output: "Start of week" (matches day).

Run "ng serve" to test.
